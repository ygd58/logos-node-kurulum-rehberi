# Logos Testnet Node Kurulum Rehberi (Türkçe)

Logos testnet node'unu komut satırından kurmak ve çalıştırmak için adım adım Türkçe rehber.

**[Rehberi PDF olarak aç / indir](https://github.com/ygd58/logos-node-kurulum-rehberi/blob/main/Logos%20Testnet%20Node%20Kurulum%20Rehberi%20%28Tu%CC%88rkc%CC%A7e%29.pdf)**

İçindekiler: gereksinimler (ADX, glibc, FUSE), logosctl ve blockchain modülü kurulumu, yapılandırma ve başlatma, doğrulama, madencilik ve lider ödülleri, portlar ve güvenlik, sık hatalar, uzun süreli işletme.

> Resmî olmayan topluluk rehberidir. Sürüm numaralarını ve bootstrap peer adreslerini [resmî dokümandan](https://docs.logos.co/blockchain/get-started/run-blockchain-node-from-cli) kontrol et.

Hata ya da eksik görürsen issue aç veya pull request gönder.
